# LLMViz-Nemotron-3.5-Lightning-30B-A3B
An educational 3d visualization of the NVIDIA-Nemotron-3.5-Lightning-30B-A3B model

This interactively shows of all the model weights inside https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16 and https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-NVFP4

Live page of it here: https://nisten.github.io/LLMViz-Nemotron-3.5-Lightning-30B-A3B/

It is all done as a single static index.html, no tools required you can just download the index.html and open it directly to see in your browser.

The volume of each shape in 3D corresponds to the actual size in bits on disk. You can click rotate and pan around while reading educational info about each layer.

Let me know of any innaccuracies or hallucinations from Fable.

Intended for educational purposes but feel free to use it however you want.
